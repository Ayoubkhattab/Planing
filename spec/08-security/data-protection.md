# Data Protection Model

| الموقع | الحماية |
|---|---|
| في النقل | TLS 1.3 خارجياً؛ mTLS داخلياً |
| في التخزين التشغيلي | تشفير بمفتاح بيانات لكل مستأجر، ملفوف بمفتاح رئيسي في KMS/HSM محلي (بيئة معزولة) |
| البيانات الشخصية | مفتاح لكل صاحب بيانات (ADR-P08) |
| Object Storage | مفاتيح المستأجر + تحقق hash (REQ-INF-004) |
| الإسقاطات | نفس مفاتيح المستأجر؛ الحقول الشخصية تُفهرس كرموز مطبّعة فقط وفق السياسة |
| النسخ الاحتياطية والأرشيف | مشفرة بمفاتيح المستأجر؛ المحو بإتلاف المفتاح يصلها |
| السجلات التقنية | بلا محتوى أعمال أو بيانات شخصية؛ معرفات وURN فقط؛ إخفاء آلي للحقول الحساسة |
| الملفات المؤقتة وذاكرة المعالجة | مشفرة، وتُحذف بانتهاء المهمة |
| الأجهزة الميدانية | تشفير المخزن المحلي بمفتاح مرتبط بجلسة المستخدم والجهاز؛ مسح عن بعد |
| سياق AI (R2) | لا يغادر حدود الخلية؛ لا تسجيل لمحتوى الـ prompt خارج سجل التدقيق المشفر |

## المفاتيح
- تدوير دوري لمفاتيح البيانات، وإعادة لف فورية عند الاشتباه.
- KMS/HSM في critical tier؛ نمط فشل مستقل في FMEA (W5).
- فصل واجبات: مشغلو المنصة لا يملكون مفاتيح المستأجرين.
