# ATAM-lite — SLC-01

## Utility tree (importance / difficulty)
| الجودة | السيناريو | الأولوية |
|---|---|---|
| Security | سحب الصلاحية يسري في الطلب التالي (QAS-SEC-003) | H / H |
| Security | عزل المستأجرين بلا تسرب ولا استدلال (QAS-SEC-001) | H / H |
| Performance | 10,000 قرار سياسة/ث بـ p95 ≤ 5 ms (QAS-PERF-009) | H / M |
| Auditability | كل أمر مدقق ذرياً وقابل لكشف العبث | H / M |
| Availability | الهوية والسياسات في critical tier (99.9 %) | H / H |

## نقاط الحساسية
| النقطة | تؤثر على |
|---|---|
| زمن قراءة مخزن security_versions لكل طلب | الأداء + فورية السحب |
| عمر حزمة السياسات في المقيّمات المضمّنة | الأمن (سياسة قديمة) + التوفر (رفض) |
| نافذة شحن audit_outbox | كشف العبث + الأداء |
| تجزئة سلاسل التدقيق (16 shard) | إنتاجية الكتابة + بساطة التحقق |

## المفاضلات المقبولة
1. **Fail-closed مقابل التوفر:** تعطل PDP أو مخزن الإصدارات يرفض الطلبات. قُبل لأن البديل تسرب. مخفف بالنسخ المتعددة وذاكرات قصيرة (RSK-018).
2. **مقيّم مضمّن مقابل مركزي:** المضمّن يلغي نداء الشبكة (أداء وتوسع)، مقابل نافذة تقادم ≤ 5 دقائق للسياسات. الصلاحيات الفردية (أدوار، تصريح) لا تتقادم لأنها تمر بفحص الإصدار في كل طلب.
3. **منع الكتابة عند تعذر التدقيق:** يضحي بالتوفر في حالة قصوى نادرة لضمان "لا تغيير بلا تدقيق".
4. **التفويض بلا كتابة متتابعة:** سحب الأصل يُبطل الفروع حسابياً. أبسط وأصح تاريخياً، مقابل تكلفة حساب السلسلة (عمق ≤ 2 يجعلها ثابتة).

## المخاطر
| المخاطرة | الحالة |
|---|---|
| RSK-018 PDP في المسار الحرج | مخففة بالتصميم المضمّن |
| تواطؤ ضابطي أمن | مقبولة (THR-S01-04) مع مراجعة دورية |
| تسرب بيانات اعتماد حساب خدمة | مقبولة ≤ 90 يوماً (THR-S01-11) |

## غير مخاطر (Non-risks)
- حدود السياقات: BC01 وBC08 لا يكتبان في مخازن بعضهما؛ BC08 يستدعي BC01 عبر OHS فقط.
- الحجم: كل الجداول مقسمة بالمستأجر؛ الـ Aggregates صغيرة (أكبرها Organization بحد 5,000 وحدة).
