# ATAM-lite — SLC-03

## Utility tree
| الجودة | السيناريو | الأولوية |
|---|---|---|
| Correctness | لا إكمال دون معايير؛ لا انتقال خارج المصفوفة | H / M |
| Security | لا اعتماد ذاتي؛ لا إسناد لغير مصرح أو غير مؤهل | H / M |
| Availability (field) | العمل الميداني يستمر دون اتصال | H / H |
| Timeliness | التصعيد ≤ 60 ث | M / M |

## المفاضلات المقبولة
1. **الأهلية fail-closed:** تعطل BC05 يمنع الإسناد مؤقتاً، مقابل عدم إسناد عمل لغير مؤهل. مخفف بذاكرة ≤ 5 دقائق.
2. **التعليق كعلم متعامد:** أبسط من حالة بذاكرة "الحالة السابقة" وأسهل للاختبار، مقابل حقل إضافي تفحصه كل الأوامر.
3. **المعايير مجمدة بعد الإسناد:** صرامة مقابل مرونة؛ التغيير عبر مهمة جديدة أو إصدار خطة.
4. **قائمة محدودة من الأوامر دون اتصال:** الاعتماد والإسناد يبقيان متصلين، مقابل أمان قرارات المراجعة.

## المخاطر
- إعادة تشغيل أوامر ميدانية بعد تغييرات متصلة تنتج تعارضات مزامنة؛ الحل في SLC-11 (CF-05). غير حاجب.
