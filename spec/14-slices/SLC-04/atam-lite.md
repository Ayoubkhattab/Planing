# ATAM-lite — SLC-04

## Utility tree
| الجودة | السيناريو | الأولوية |
|---|---|---|
| Correctness | الفصل يعيد الحالة بدقة؛ الهوية مؤرخة (P-42، P-44) | H / H |
| Security | لا كشف لكيانات أو ادعاءات مخفية عبر التعارضات والطوابير والعناقيد | H / H |
| Accuracy | استدعاء المرشحين ≥ 95 % للأسماء العربية (QAS-ER-001) | H / H |
| Performance | حمل العناقيد على القراءة ≤ 20 % (QAS-PERF-015) | M / M |

## المفاضلات المقبولة
1. **لا دمج آلي حتى عند الثقة شبه الكاملة:** عبء مراجعة مقابل منع دمج خاطئ يصعب اكتشافه. مخفف بترتيب الطابور حسب الدرجة، ودقة ≥ 60 %.
2. **حالات ثنائية لا جماعية:** أبسط وأوضح للتدقيق، مقابل عدد حالات أكبر عند العناقيد الكبيرة.
3. **الكشف بهوية نظام والرؤية عند القراءة:** يكشف كل التعارضات الحقيقية، مقابل أن مستخدمين مختلفين يرون مجموعات تعارض مختلفة (مقصود).
4. **تحديث العناقيد في نفس معاملة القرار:** صحة فورية مقابل حد 50 عضواً للحفاظ على زمن المعاملة.
