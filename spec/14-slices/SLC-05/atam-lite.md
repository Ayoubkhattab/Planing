# ATAM-lite — SLC-05

## Utility tree
| الجودة | السيناريو | الأولوية |
|---|---|---|
| Security | P-51..P-53: المخفي لا يغير أي مخرج | H / H |
| Security | السحب يسري فوراً رغم تأخر الفهرس | H / M |
| Performance | 500 بحث/ث، p95 ≤ 1 ث | H / H |
| Usability | استدعاء ≥ 95 % للأسماء العربية | H / M |
| Recoverability | إعادة بناء ≤ 24 ساعة دون انقطاع | M / M |

## نقاط الحساسية
- **حجم الحقائق المتداخلة** يحدد تكلفة الفهرسة والاستعلام.
- **زمن LabelCheck** على كل صفحة يدخل مباشرة في زمن البحث.

## المفاضلات
1. **فهرسة على مستوى الحقيقة** تضاعف حجم الفهرس، مقابل إغلاق قناة الاستدلال الأخطر (العثور على كيان بقيمة مخفية).
2. **LabelCheck لدى المالك بدل سجل تسميات مركزي** (CR-47): نداء إضافي لكل صفحة، مقابل احترام الملكية والصحة الفورية دون كتابة عابرة للسياقات.
3. **إعادة ملء الصفحة بعد الإسقاط** قد تزيد الزمن قليلاً عند تأخر الفهرس، مقابل صفحات كاملة.
