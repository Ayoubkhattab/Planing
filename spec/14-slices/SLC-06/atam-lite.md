# ATAM-lite — SLC-06

## Utility tree
| الجودة | السيناريو | الأولوية |
|---|---|---|
| Performance | تنبيه حرج ≤ 5 ث طرفاً لطرف | H / H |
| Security | لا تسرب عبر التنبيهات والإشعارات والبلاطات والأعداد | H / H |
| Availability (field) | الوعي بالموقف مع تعذر الدفع | M / M |

## المفاضلات
1. **مقيّمان منفصلان:** تعقيد تشغيلي إضافي مقابل عدم ربط زمن التنبيه الحرج بإعادة حساب العضوية.
2. **لا تنبيه منقوص:** مستخدم غير مصرح لا يعلم أن شيئاً حدث؛ قد يفوته سياق، مقابل إغلاق قناة استدلال. التصعيد عبر المصرح لهم.
3. **ذاكرة بلاطات حسب نطاق الصلاحية:** نسبة إصابة أقل، مقابل عدم التسرب. مخفف بأن عدد النطاقات المتمايزة صغير (أدوار × مستويات).
4. **لا خدمات دفع عامة:** اعتماد على قناة داخلية، مقابل الالتزام بالبيئة المعزولة.
