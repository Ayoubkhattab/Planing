# ATAM-lite — SLC-12a

## Utility tree
| الجودة | السيناريو | الأولوية |
|---|---|---|
| Compliance | لا إتلاف لمجمّد؛ لا بقاء لما يجب إتلافه أو محوه | H / H |
| Privacy | المحو يصل للنسخ الاحتياطية فعلاً (بوابة الاستعادة) | H / H |
| Scalability | الإتلاف بمليار سجل دون حذف صف بصف | H / M |

## المفاضلات
1. **حاويات شهرية:** دقة الإتلاف بمستوى الشهر لا اليوم؛ السجل قد يبقى حتى نهاية شهره قبل الإتلاف (≤ 31 يوماً إضافية). مقبول مقابل الإتلاف الشامل للنسخ.
2. **تشفير مزدوج للبيانات الشخصية:** تكلفة معالجة إضافية مقابل مسارين مستقلين (الإتلاف والمحو).
3. **بوابة الاستعادة تبطئ الاستعادة** بزمن إعادة تطبيق السجل، مقابل ضمان حقيقي.

## المخاطر
- RSK-025 (جديد): الاعتماد الحرج على KMS/مخزن المفاتيح؛ فقدانه = فقدان كل البيانات. مخفف بـ HSM مكرر، ونسخ مفاتيح KEK خارج الخط بإجراء شخصين، واختبارات استعادة.
